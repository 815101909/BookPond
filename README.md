# 晓世界小程序

一个专注于多语言新闻阅读和翻译的小程序，帮助用户更好地了解世界。

## 页面结构

### 1. 首页 (index)
- 顶部导航栏：包含搜索和用户中心入口
- 新闻列表展示：
  - 新闻卡片包含封面图、标题、摘要
  - 支持下拉刷新和上拉加载更多
  - 点击新闻卡片进入详情页

### 2. 新闻详情页 (news-detail)
- 顶部导航：返回按钮、收藏按钮
- 新闻头部信息：
  - 新闻标题（支持多语言）
  - 新闻封面图
  - 新闻亮点摘要
- 新闻内容区域：
  - 正文内容（支持多语言）
  - 对照翻译功能
  - 音频播放功能
  - 打印功能

### 3. 打印页面 (print)
- 顶部语言选择栏
- A4预览区域：
  - 支持多语言切换
  - 显示打印效果
- 底部文字：
  - "读万卷书，行万里路，观万千象。"

### 4. 用户中心 (user)
- 用户信息展示
- 收藏列表
- 阅读历史
- 设置选项

## 主要功能

### 1. 多语言支持
- 支持中文、英文、德文等多种语言
- 实时切换语言显示
- 对照翻译功能

### 2. 音频播放
- 支持新闻内容朗读
- 多语言音频播放
- 播放进度显示

### 3. 打印功能
- A4格式打印预览
- 多语言打印支持
- 自定义打印样式

### 4. 收藏功能
- 收藏新闻文章
- 收藏列表管理
- 快速访问收藏内容

## 使用说明

1. 首页浏览新闻列表
2. 点击新闻卡片进入详情页
3. 在详情页可以：
   - 切换语言查看不同版本
   - 使用音频播放功能
   - 收藏文章
   - 打印文章内容
4. 在用户中心管理收藏和历史记录

## 注意事项

1. 首次使用需要授权用户信息
2. 音频播放需要网络连接
3. 打印功能需要连接打印机
4. 部分功能可能需要微信最新版本支持
