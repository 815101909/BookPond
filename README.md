# 小舟摇书池小程序

一个专注于多语言新闻阅读、翻译和学习的小程序平台，帮助用户通过阅读提升语言能力，了解世界动态。

## 项目特色
- 多语言新闻阅读与翻译
- 会员积分与打卡系统
- 语音朗读与跟读功能
- 个性化学习记录跟踪

## 核心功能页面

### 1. 首页 (index)
- **功能概述**：展示各类新闻文章，提供快速搜索和用户中心入口。
- **主要内容**：
  - **顶部导航栏**：包含搜索图标和用户头像，点击可进入搜索页面或用户中心。
  - **新闻列表**：以卡片形式展示新闻，每张卡片包含封面图、标题和摘要。支持下拉刷新加载最新内容，上拉加载更多历史新闻。
  - **交互**：点击新闻卡片可进入新闻详情页。

### 2. 新闻详情页 (news-detail)
- **功能概述**：展示新闻的详细内容，并提供多语言、翻译、音频播放和打印等功能。
- **主要内容**：
  - **顶部导航**：包含返回按钮和收藏按钮，方便用户操作。
  - **新闻头部**：展示新闻标题（支持多语言切换）、新闻封面图和新闻亮点摘要。
  - **新闻内容区域**：
    - **正文**：支持多语言显示，用户可根据需要切换语言。
    - **对照翻译**：提供原文与译文对照功能，辅助语言学习。
    - **音频播放**：支持新闻内容朗读，方便用户听读。
    - **打印**：提供将新闻内容导出为A4格式进行打印的功能。

### 3. 打印页面 (print)
- **功能概述**：提供新闻内容的A4格式打印预览和设置。
- **主要内容**：
  - **顶部语言选择栏**：方便用户选择打印内容的语言。
  - **A4预览区域**：实时显示打印效果，支持多语言切换。
  - **底部文字**：展示励志名言“读万卷书，行万里路，观万千象。”

### 4. 用户中心 (profile)
- **功能概述**：管理用户个人信息、收藏、阅读历史和应用设置。
- **主要内容**：
  - **用户信息**：展示用户头像、昵称等基本信息。
  - **收藏列表**：查看和管理用户收藏的新闻文章。
  - **阅读历史**：记录用户阅读过的新闻，方便回顾。
  - **设置选项**：包括语言设置、通知设置等。

### 5. 登录页面 (login)
- **功能概述**：用户登录入口，支持手机号登录。
- **主要内容**：
  - **手机号登录**：通过手机号获取验证码进行登录。
  - **用户协议与隐私政策**：提供用户协议和隐私政策的查看入口。

### 6. 用户协议与隐私政策页面 (agreement)
- **功能概述**：展示用户协议和隐私政策的详细内容。
- **主要内容**：
  - **动态内容加载**：根据传入参数（`type=privacy` 或 `type=agreement`）动态加载并显示对应的文本内容。
  - **背景色统一**：与登录页面保持一致的背景色，提供统一的视觉体验。

### 7. 会员中心 (membership)
- **功能概述**：展示会员特权和会员购买/续费选项。
- **主要内容**：
  - **会员特权介绍**：详细说明会员享有的专属功能和优惠。
  - **会员图片展示**：通过云存储获取并展示会员宣传图片。
  - **购买/续费入口**：引导用户进行会员服务的购买或续费操作。

## 技术架构

### 前端技术栈
1. **微信小程序原生开发**
   - 使用WXML/WXSS/JS进行页面开发
   - 采用小程序原生组件和API
   - 支持多语言切换和国际化

2. **状态管理**
   - 使用小程序原生`getApp()`全局状态管理
   - 关键数据通过`setData`实现组件间通信

3. **UI组件库**
   - 自定义组件：导航栏、图标、模态框等
   - 采用Flex布局实现响应式设计

### 后端技术栈
1. **云开发**
   - 基于微信云开发(CloudBase)
   - 使用云数据库存储用户数据和内容
   - 云函数处理业务逻辑

2. **云服务**
   - 云存储：存储图片、音频等媒体资源
   - 云调用：直接调用微信开放接口

3. **第三方服务集成**
   - 微信支付：会员订阅和支付功能
   - 短信服务：手机号登录验证
   - TTS服务：文本转语音功能

### 关键技术实现
1. **多语言支持**
   - 动态加载语言包
   - 实时切换无需刷新

2. **音频处理**
   - 音频播放控制
   - 跟读录音功能
   - 语音评测接口

3. **性能优化**
   - 图片懒加载
   - 数据分页查询
   - 本地缓存策略

### 1. 界面设计
- 清新简约的视觉风格

- 流畅的动画效果

### 2. 性能优化
- 图片懒加载

## 用户使用指南

1. 首页浏览新闻列表
2. 点击新闻卡片进入详情页
3. 在详情页可以：
   - 切换语言查看不同版本
   - 使用音频播放功能
   - 收藏文章
   - a4打印页面
4. 在用户中心管理收藏和历史记录

## 重要注意事项

1. 首次使用需要授权用户信息
2. 音频播放需要网络连接
3. 部分功能可能需要微信最新版本支持
